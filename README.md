# 👁️ Robot's Eye

**Robot's Eye** — desktop-приложение для компьютерного зрения, позволяющее в реальном времени анализировать изображение с камеры и обнаруживать объекты с помощью нейронной сети YOLO.

Проект создан как практическая работа с **C# и компьютерным зрением**: от получения изображения с камеры до обработки кадров и отображения результатов детектирования пользователю.

> Проект объединяет классическое desktop-приложение на .NET с современными технологиями Computer Vision и Machine Learning.

---

## ✨ Возможности

* 📷 получение изображения с камеры в реальном времени;
* 🤖 обнаружение объектов с помощью YOLO;
* 🎯 определение положения обнаруженных объектов;
* 📦 отображение результатов детектирования поверх изображения;
* ⚡ обработка видеопотока в реальном времени;
* 🖥️ графический интерфейс Windows-приложения;
* 🧩 разделение логики приложения и моделей данных.

## 🧠 Как это работает

Обработка изображения строится примерно следующим образом:

```text
┌─────────────┐
│   Webcam    │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ Video Frame │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ Preprocess  │
│   Image     │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ YOLO Model  │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ Detections  │
│ + Confidence│
│ + Bounding  │
│   Boxes     │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ UI / Frame  │
│   Output    │
└─────────────┘
```

Каждый кадр с камеры проходит через модель детектирования. Для найденных объектов модель возвращает класс объекта, координаты ограничивающего прямоугольника и confidence score.

## 🚀 Запуск

### Требования

Перед запуском необходимо установить:

* Windows;
* .NET SDK;
* веб-камеру;
* необходимые зависимости проекта.

### Клонирование

```bash
git clone https://github.com/Ermanchick/Robot-s-eye.git
cd Robot-s-eye
```

### Запуск

```bash
dotnet restore
dotnet run
```

Либо открыть проект в **Visual Studio** и запустить его через `F5`.

> Для работы детектирования камера должна быть доступна операционной системе.
